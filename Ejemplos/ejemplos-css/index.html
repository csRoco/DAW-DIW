Ejemplos de CSS

Cada ejemplo es una página completa con su propia hoja de estilos en css/styles.css. Al final de cada página hay un «laboratorio» con el concepto más delicado del tema, y al principio de cada CSS, propuestas para experimentar.

  1. Unidades: ruta de montaña con %, max-width, rem, em y vh.
  2. Modelo de caja: carta de una cafetería con content, padding, border y margin.
  3. Tamaños: tarifas de un gimnasio con width, height, box-sizing y margin.
  4. Bordes: tablón de avisos con estilos, abreviadas y el patrón «general y después detalle».
