¿Qué unidad uso?

Laboratorio de unidades de medida en CSS. Cada bloque explica cuándo usar una unidad, muestra el código y ofrece una demostración que puedes manipular para ver los valores reales en píxeles que calcula el navegador.

  • pxBordes, sombras y detalles pequeños

% Porcentaje

Anchos de contenedores y columnas.

Un porcentaje se calcula respecto a su elemento padre. En width, es un porcentaje del ancho del contenedor; por eso las columnas se adaptan solas cuando el contenedor cambia.

.contenedor {
  width: 90%;          /* 90 % del padre */
  max-width: 60rem;    /* tope para pantallas grandes */
  margin-inline: auto;
}
.lateral   { width: 30%; }
.principal { width: 70%; }
Ojoheight: 50% solo funciona si el padre tiene una altura definida. Y padding o margin en % se calculan siempre sobre el ancho del padre, incluso los verticales.

rem Root em

Tipografía, espaciados generales, media queries.

1rem equivale al font-size del elemento raíz (html). Por defecto los navegadores usan 16px, así que 1.5rem = 24px. Si el usuario aumenta el tamaño de letra en su navegador, todo lo definido en rem crece de forma proporcional: es la unidad más respetuosa con la accesibilidad.

html { font-size: 100%; }  /* respeta la preferencia del usuario */

h2   { font-size: 1.75rem; margin-bottom: .5rem; }
p    { font-size: 1rem; }
body { padding: 1.5rem; }

/* 40rem = 640px con el tamaño por defecto */
@media (min-width: 40rem) {
  .rejilla { grid-template-columns: 1fr 1fr; }
}
Error frecuentehtml { font-size: 16px; } anula la preferencia de tamaño del usuario. Usa 100% (o no lo declares).
Detalle de las media queriesDentro de @media, rem y em se calculan con el tamaño de letra inicial del navegador, no con el font-size que declares en html. En la demo verás que cambiar el tamaño raíz no mueve el punto de ruptura; cambiar el ancho, sí.

em Em

Espaciados ligados al texto de un componente.

1em equivale al font-size del propio elemento (y en la propiedad font-size, al del padre). Si el padding de un botón está en em, al hacer el botón más grande el relleno crece con él y las proporciones se mantienen.

.boton {
  font-size: 1rem;
  padding: .6em 1.2em;    /* proporcional a SU texto */
  border-radius: .4em;
}
.boton--grande  { font-size: 1.375rem; }
.boton--pequeno { font-size: .875rem; }
Error frecuente: el efecto compuestoSi usas em en font-size de elementos anidados, cada nivel multiplica al anterior: 1.2 × 1.2 × 1.2… Para el tamaño de letra suele ser mejor rem; reserva em para espaciados internos del componente.

vw / vh Viewport

Secciones a pantalla completa, escala con el viewport.

1vw es el 1 % del ancho de la ventana y 1vh el 1 % de su alto. No dependen de ningún contenedor, sino de la pantalla. Son ideales para una portada (hero) que ocupe toda la ventana.

.hero {
  min-height: 100vh;    /* respaldo */
  min-height: 100dvh;   /* alto dinámico en móviles */
  padding-inline: 5vw;
}
.hero h1 {
  /* nunca menos de 1.5rem ni más de 3.5rem */
  font-size: clamp(1.5rem, 1rem + 4vw, 3.5rem);
}
Accesibilidad (enlace con UT5)Un texto con font-size: 5vw a secas no aumenta al hacer zoom de texto, lo que puede incumplir el criterio WCAG 1.4.4 (cambio de tamaño del texto). Combínalo con rem dentro de clamp().

Actualización respecto a la programacióndvh, svh y lvh (2022) resuelven el problema de 100vh en móviles, donde la barra del navegador aparece y desaparece.

px Píxel

Bordes, sombras y detalles pequeños.

El px es una unidad absoluta: no cambia con el tamaño de letra ni con el contenedor. Justo por eso es la adecuada para detalles que deben verse igual de finos siempre: un borde de 1px, una sombra sutil, un contorno de foco.

.tarjeta {
  border: 1px solid #d5dae5;
  box-shadow: 0 2px 6px rgb(20 24 40 / .12);
  border-radius: 8px;
}
:focus-visible { outline: 2px solid currentColor; }
Nota técnicaEl px de CSS es un píxel de referencia, no un píxel físico: en una pantalla de alta densidad, 1px CSS puede ocupar 2 o 3 píxeles del dispositivo.

Todo junto en un componente

Cada unidad en su sitio: así suele quedar una tarjeta real.

.ficha {
  width: 90%;             /* %   ancho respecto al padre */
  max-width: 28rem;       /* rem tope ligado a la tipografía */
  padding: 1.5rem;        /* rem espaciado general */
  border: 1px solid #d5dae5;   /* px detalle */
  border-radius: 12px;         /* px detalle */
  box-shadow: 0 4px 12px rgb(20 24 40 / .12); /* px */
}
.ficha h4 { font-size: 1.5rem; }  /* rem tipografía */
.ficha a {
  padding: .5em 1em;      /* em  ligado al texto del enlace */
  border-radius: .4em;
}
.portada {
  min-height: 100dvh;     /* vh  pantalla completa */
}
